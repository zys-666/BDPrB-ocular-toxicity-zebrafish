# Data are not stored in this repository

No expression matrix, sequence file or trajectory is included. `.gitignore`
excludes `data/`, `out/`, `tables/`, `figures/` and the usual MD artefacts, so a
fresh clone cannot run the pipeline until the project tree described in README.md
under "Data layout" is restored.
